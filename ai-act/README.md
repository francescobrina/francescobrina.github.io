# AI Act Atlas

**Live app:** https://francescobrina.github.io/ai-act/

Workspace statico e local-first per preparare un registro operativo di sistemi IA. Nessun backend, database, servizio di analytics o account: dati e risposte vengono memorizzati in `localStorage` e possono essere esportati in JSON (backup completo), CSV (controlli e azioni) e report HTML stampabile in PDF.

## Workflow operativo

1. Creare un sistema oppure utilizzare il caso demo contrassegnato da dati fittizi.
2. Compilare finalità, ruolo, contesto UE, Allegato I/III, indicatori di pratiche vietate, trasparenza, GPAI e dati personali.
3. Consultare l'esito di **screening orientativo** e la motivazione dei possibili trigger. Le risposte sconosciute non equivalgono a esenzioni.
4. Assegnare stato, proprietario, scadenza interna e riferimento delle evidenze ai controlli pertinenti.
5. Esportare report HTML (PDF tramite stampa), piano azioni CSV o backup JSON.
6. Per dichiarare completato un controllo occorre almeno una evidenza o motivazione. “Non applicabile” richiede una motivazione.

## Avvertenza

Non è software di conformità certificato: non identifica autonomamente tutte le eccezioni, non effettua audit esterni e non sostituisce avvocati, DPIA, FRIA né procedure di valutazione della conformità. I controlli generati sono una base di lavoro da contestualizzare. Le informazioni confidenziali non devono essere immesse su dispositivi non gestiti; i backup esportati vanno protetti dall'utente.
