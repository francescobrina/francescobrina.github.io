Per i file molto grandi

Per 1 GB di documenti, per Word, Excel, PowerPoint o file particolarmente problematici, usa la versione desktop: il browser può esaurire la memoria. Non esiste una soglia garantita sul web.

Questa versione web usa la libreria pdf-lib, caricata da un CDN. Non invia i documenti al CDN; soltanto il codice della libreria viene scaricato. Le immagini animate vengono trattate come singola immagine.
