# Giusi Morreale — Sarta Modellista Professionale

Sito vetrina di Giusi Morreale dedicato alle creazioni su misura, modifiche sartoriali e modellistica professionale a Ferrara e provincia.

- **Sito:** https://francescobrina.github.io/giusi-morreale/
- **Contatti:** 328 1717879 · givol1@hotmail.it
- **Tecnologie:** HTML5, CSS3, JavaScript; nessun backend, database o form di raccolta dati.
- **Design:** avorio, rosa antico, bordeaux, illustrazioni originali SVG, responsive e con supporto alla navigazione da tastiera.

## Pubblicazione

Questa sottocartella è ospitata nel repository GitHub Pages `francescobrina.github.io`, senza modificare la homepage esistente. Perché il collegamento pubblico funzioni, il repository deve avere GitHub Pages attivo sul ramo `master` e radice `/`.

## Personalizzazioni

Il contenuto si trova in `index.html`; `favicon.svg` contiene l'icona. I pulsanti chiamano il numero indicato o aprono un messaggio email nell'applicazione del visitatore. Non viene chiesto di inserire dati personali su un form.

Non sono stati inventati indirizzo fisico, prezzi, orari, recensioni o fotografie di lavori eseguiti.
