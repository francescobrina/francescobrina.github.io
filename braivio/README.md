# BrAIvio — Demo commerciale

Demo navigabile del gestionale modulare per PMI, pubblicata con GitHub Pages.

URL previsto: https://francescobrina.github.io/braivio/

## Funzioni dimostrative
- Dashboard KPI e trend economici da commesse completate
- CRM e clienti
- Commesse: stato, progressione, valori, costi e margini
- Preventivi in Kanban, accettazione e conversione automatica in commessa
- Magazzino con soglie minime, quantità, valorizzazione
- Attività con scadenze e completamento
- Analisi economiche e report di redditività
- Regole/avvisi locali dimostrativi
- Copilot *rule-based* su dati di esempio (non è connesso a un servizio AI)
- Configurazione scenario aziendale, esportazione JSON, ripristino dati

## Ambito e privacy

Questa è una **demo pubblica statica**, non un ERP di produzione. Usa solo dati fittizi. Le modifiche vengono salvate in **localStorage del browser**, non sono condivise tra dispositivi né inviate a server. Non richiede account, chiavi API o password. Le notifiche e l'AI sono simulazioni dichiarate. Le funzioni enterprise (autenticazione, multiutente, integrazioni, backup cloud, automazioni server-side e AI reale) richiedono backend dedicato.

Si distribuisce senza build: GitHub Pages serve index.html, style.css, app.js e favicon.svg. Non modificare il sito personale in root né altre cartelle.

Nota marchio: "BrAIvio" è un nome provvisorio e richiede verifica legale prima dell'utilizzo commerciale definitivo.
